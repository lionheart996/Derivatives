# 📘 01_derivatives.ipynb – Introduction to Derivatives with Python

This Jupyter notebook provides a hands-on exploration of **derivatives in calculus**, combining theoretical insights with Python-based visualizations and numerical examples.

---

## 🧠 What You’ll Learn
- The concept of a derivative as a rate of change
- Graphical intuition using slope of tangent lines
- Symbolic differentiation using `SymPy`
- Numerical approximation of derivatives with finite differences
- Plotting functions and their derivatives with `Matplotlib`
